# C：检测输入、诊断与 DCFO 接入状态

## 本次交付

提供 LOF/iForest 的可复现初步检测和 LOF 重复特征诊断。结果不以达到理想 AUC 为前提，不使用评估标签训练、调转分数或自动挑选最优 k。

脚本接受 B 交付的 feature_table.csv，严格使用 7 个 `_z` 特征和 `burstiness_missing`。ID 和两个标签列不进入模型；不重复标准化、不删除重复特征账号、不加抖动。

默认只在 `is_injected=0` 的账号上拟合和评价。它是固定交付缩放参数下的传导式评估，不是独立测试集；排除了选作注入的 300 个账号，不能称作完整注入前 clean 全表。Yelp 过滤标记聚合形成的标签是代理标签，不是人工核验真值。

## 运行

在仓库根目录，使用安装了 requirements.txt 中 numpy、pandas、scipy、scikit-learn 的 Python：

```bash
python src/models/detection_diagnostics.py --input data/processed/feature_table.csv --population native --neighbors 20 50 100 600 --report results/c_detection_diagnostics.md
python -m unittest discover -s tests -p "test_detection_diagnostics.py"
```

`--input` 可指向交接文件的实际位置，不要求复制数据。账号级分数和完整 JSON 默认存入被 gitignore 排除的 `data/processed/c_diagnostics/`。聚合 Markdown 报告可以提交。脚本采用 2 个工作线程；较大 k 会增加近邻数组占用，建议逐个运行，不并行启动多个大实验。

固定比较 k=20/50/100/600。600 用于检查邻居数超过最大相同特征组时的密度退化，不是根据标签挑选的推荐参数。阈值 1.5 仅用于诊断计数，不代表已确定正式 DCFO 阈值。

P@50 以分数降序、ID 升序打破并列，同时报告边界并列下的最小／最大值。AUC 使用原始连续分数；两种模型都统一为越大越可疑。只有一种标签时 AUC 为 NA，不伪造数值。

## 接入检查与当前问题

- 提供的表共 38,063×18，ID 唯一，无 NaN/Inf，标准化核对通过。
- 注入日志是 300 个账号、1,500 条特征记录；A/B/C 各 100 个。
- 账号的特征相同不等于重复账号。当前全表去掉每组首条后有 26,179 行特征重复，最大同值组 583 个账号。
- burstiness 缺失标记有 32,918 个，其中少于 3 条评论的为 32,666 个，其余 252 个。数据字典中的“3,252”应核对。
- 数据字典已声明 A/C 模板 burstiness 方向待修。本 PR 不改注入脚本，避免未经协调改变共同实验数据。
- active_days 是首末评论跨度加一天，不是注册时长。

## DCFO 验证状态（独立于本次检测）

此前已完成作者二维数值核心的本地适配验证：随机种子 0，10 个二维点，k=2，检测阈值 1.10；原分数 1.8881236336580502，反事实分数 1.0999027149544687。作者实现与 sklearn 替换原点后重新拟合的分数一致。

搜索目标使用 1.0999 留出数值余量，检测阈值仍为 1.10。适配解决导入及未使用依赖问题，省略背景网格，未声称完整复现论文。原作者来源：https://github.com/tommasoamico/DCFO 。该第三方代码未拷入本 PR。

尚未完成正式账号 Top-20 解释。评分稳定性检查后，再做单账号运行，并区分：

1. 模型有效性：替换点后独立复算，LOF 是否不超过阈值。
2. 行为可行性：计数整数、比例范围、派生特征等式是否成立；不能把 binary 缺失标记连续改成小数。
3. 解释对应性：与实际注入改动集合／方向对照，不能仅凭反事实有效就声称找到因果原因。

当前注入仅修改汇总特征，未同时生成评论和图边；跨方法规避实验需先统一特征与图上的攻击语义。

## 本轮诊断结论

37,763 个未注入账号，固定输入与评分口径：

| k | AUC | P@50 | 零 k 距离账号数 | 最大 LOF | 重复值警告 |
|---|---:|---:|---:|---:|---|
| 20 | 0.470931 | 0.20 | 22,395 | 约 7.24×10^9 | 有 |
| 50 | 0.480585 | 0.10 | 16,000 | 约 2.99×10^9 | 有 |
| 100 | 0.485508 | 0.04 | 8,103 | 约 3.85×10^9 | 有 |
| 600 | 0.498626 | 0.14 | 0 | 123.148 | 无 |

k=50/100/600 的 Top-20 与 k=20 均无交集。k=600 消除了本轮精确重合导致的零距离和相关警告，但 AUC 仍近随机；不能据此推荐 k=600 为正式参数，也不能称“模型已修好”。后续需讨论特征信息量、分人群分析和参数选择验证方案，而不是继续用标签找一个看起来好看的 k。

完整自动生成报告见 `results/c_detection_diagnostics.md`。iForest AUC=0.416999、P@50=0.14。未自动翻转低于 0.5 的 AUC。
