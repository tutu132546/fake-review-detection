# 实验3：受控离线行为修改后的检测保留情况

在原定Top-20上，用数值有效的DCFO解释中绝对改动最大的一维选择一个预设行为类别。仅调整该账号已经生成的模拟评论，不修改真实历史、不增删评论、不迭代搜索。时间类调整模拟评论时间到该账号历史时间分位点；评分类调整为历史众数；数量类因不允许删评而不操作，超时也不操作。每个候选编辑再核对目标特征方向，方向不一致则撤销；direction_confirmed统计最终事件重算后方向仍匹配的人数。不保证复现连续目标的精确幅度。本实验是类别指导的离线情景，不是作者算法直接输出的可执行方案。

每个生成模型版本独立进行一次集体修改，按评论事件重新计算全体账号特征和商品均分；同一批账号及scaler、参数和随机种子保持固定，三个检测器在编辑前、后分别重拟合。各检测器的门槛固定为原始未接管组的95%分位（严格大于）；不是部署中冻结模型的在线攻击成功率。DBSCAN为到最近核心点的距离分数。
