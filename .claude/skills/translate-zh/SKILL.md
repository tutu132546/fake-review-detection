# 英译中翻译

把用户提供的英文内容翻译成**简体中文**。

## 输入

- 参数是一段英文文本：直接翻译。
- 参数是文件路径（如 `README.md`、`paper/*.md`）：先读取文件，再翻译全文。
- 没有参数：翻译用户在对话中最近给出的英文内容；如果没有，询问要翻译什么。

## 翻译要求

1. 译文准确、通顺，符合中文表达习惯，不逐词硬译。
2. 保留原有格式：Markdown 标题、列表、表格、链接、图片引用保持不变，只翻译文字。
3. 代码块、命令、变量名、函数名、文件路径、URL **不翻译**；代码中的注释可以翻译。
4. 专业术语首次出现时用"中文（English）"形式，例如"虚假评论检测（fake review detection）"、"准确率（accuracy）"；之后直接用中文。
5. 人名、产品名、数据集名、模型名（如 BERT、Yelp）保留英文。
6. 数字、公式、单位保持原样。

## 输出

- 短文本：直接在回复中给出译文，不加多余解释。
- 文件：默认在回复中输出译文；如果用户要求保存，写到原文件旁边，文件名加 `.zh` 后缀（例如 `README.zh.md`），不要覆盖原文件。
- 若原文有歧义，在译文末尾用一两行"译注"说明。
